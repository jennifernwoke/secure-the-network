# secure-the-network
This project was made for my Network Security module. The aim was to implement multiple network security technologies/features into a pre-built simulated network (via Packet Tracer), write a detailed report on the implementation outlining all the security features and finally do an in-person demonstration/presentation showcasing your implementation.

It was tough and took me quite a long time and mistakes were made. Sections of the brief weren't added due to complications with the routers and or switches and without the right planning and the documentation of each stage of the project can make this project draining. I worked hard and I'm proud of my project and have learned alot about myself going through it.
